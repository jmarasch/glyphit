# Credits

## Iconize

GlyphIt is a fork of [Iconize](https://github.com/FlorianWoelki/obsidian-iconize)
by **[Florian Woelki](https://github.com/FlorianWoelki)**, which was
[retired in 2025](https://github.com/FlorianWoelki/obsidian-iconize/discussions/646).

Iconize is the origin of essentially everything GlyphIt does: icons on files and
folders, in tabs, above titles, inline in notes, custom rules, frontmatter
integration and the plugin API were all designed and built there over several
years. GlyphIt keeps that work and reworks how icon packs are stored so that
very large packs stay fast.

Iconize is MIT licensed, and GlyphIt remains MIT licensed. The original
copyright is retained in [LICENSE](https://github.com/jmarasch/glyphit/blob/main/LICENSE)
alongside this fork's, as the license requires.

Thank you to Florian for building it and for releasing it under a license that
let the work continue.
